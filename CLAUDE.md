# market-impact-research

Shared context for the whole PhD is in `../CLAUDE.md`. This file covers this
repository.

## Layout

- `shared-methodology/`: the data pipeline package `crypto_market_data`.
  - Binance (and Bybit) downloads, parsing to canonical fills;
  - `timestamp_direction_v1` events, series, bookTicker quotes.
- `crypto-impact-study/`: the academic impact/decay study. It feeds thesis
  chapter 5 and the market-impact paper. Its standard is explanation and
  careful inference.
- `alpha-search/`: trading research, driven by
  `alpha-search/HYPOTHESIS_LEDGER.md`. See below.
- `shared-data/`: a symlink to the external SSD (`/Volumes/Crypto Research
  Data/...`). It holds hundreds of GB and is never committed. If the SSD is not
  mounted, data paths fail.
- `chris-binance/`: not part of the current work. Ask before touching it.

## Environment

- **Python:** `shared-methodology/.venv/bin/python` (3.12; also set in
  `.vscode/settings.json`). Scripts add `alpha-search/src` and
  `shared-methodology/src` to `sys.path` themselves.
- **Tests:** `shared-methodology/.venv/bin/python -m pytest -q shared-methodology/tests`,
  and the same for `alpha-search/tests`.
- **Notebooks:** kernel "Alpha Search (.venv)" (`alpha-search-venv`). Notebooks
  are generated by `alpha-search/scripts/build_*_notebook.py`, so edit the
  builder, not the `.ipynb`.
- **Memory:** the machine has 24 GB. Heavy jobs (monthly parses, bar builds,
  bookTicker) run one symbol at a time, never several heavy jobs at once.

## Alpha-search protocol (non-negotiable)

- **Register before running.** Every predictive test is written into
  `HYPOTHESIS_LEDGER.md` *before* any result is seen. Implementation choices
  go into run notes before results. Entries are never deleted; failures stay
  recorded.
- **The sample register is binding.** Respect the locked and prospective
  periods. **P-006** (prospective C-006 test, data from 2026-09):
  - `alpha-search/scripts/p006_monthly_data.py` only downloads and
    quality-checks;
  - no signal, return or edge may be computed on P-006 data before a look is
    allowed (look 1 needs data through 2027-08).
- **Objective and costs** are in the ledger's frozen assumptions:
  - gross threshold T(τ) = max(1.5, min(2√(τ/5 min), 10)) bps;
  - target fees 1 bp maker / 2 bps taker;
  - Binance base tier 5/2 for reference.
- **Perpetual P&L** uses simple returns via `alpha-search/src/alpha_search/perp_pnl.py`
  (quantity × price change, funding on notional). Never use log returns for
  perp P&L.
- **Judge economics trade-weighted** (P&L per trade), with day-clustered
  inference. Always report results with the best 10 days removed.

## Git hygiene

- Do not commit generated files over about 50 MB. GitHub rejects files over
  100 MB. `alpha-search/reports/c006/trades.parquet` is ignored for this
  reason.
- Check sizes before committing new report outputs.
